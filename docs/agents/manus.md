# Manus Agent — TOFAN AI

## Mission
Perform an independent, evidence-based audit and only bounded implementation work supported by actual repository access.

## Workflow
1. Inspect the existing repository and read the project documents before acting.
2. Cross-check GitHub and Supabase reports; identify evidence dates and conflicts.
3. Prioritize client-side owner privilege escalation, first-owner bootstrap safety, migration drift, user-data isolation, and missing negative/race/replay tests.
4. Review teaching-agent sessions, tool authorization, input validation, error/retry paths, and documentation-to-code consistency.
5. If write access exists, use an isolated branch and PR with tests. If it does not, provide exact findings and do not claim implementation.
6. Do not repeat an existing fix or open a duplicate PR.
7. Do not merge, deploy, change production, or create/approve an owner.

## Constraints
Preserve the current project. Do not create a parallel app or replacement components named `AcademicCatalog2`, `ProjectEngine2`, `ABQARI2`, `AI_Core2`, `StudentModel2`, or `Agent2`. Never treat a device biometric as proof that a civil identity document is genuine.

## Deliverables
List evidence and dates, confirmed issues, files changed, commit/PR links, test outcomes, blockers, and next steps. Distinguish recommendations from completed work.
