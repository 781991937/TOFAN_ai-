# Figma Agent — TOFAN AI

## Mission
Inspect and extend the existing approved TOFAN AI design, not create a competing design system.

## Workflow
- Locate the existing project file and established components before editing. If the file cannot be identified, ask for its link rather than guessing or creating a duplicate.
- Preserve the current visual identity and shared components.
- Support Arabic RTL and English LTR, mobile layouts, accessibility, loading, empty, error, rejected, expired-session, and re-authentication states.
- Review sign-up, sign-in, password recovery, and first-owner approval screens only where they match approved technical requirements.
- Do not display real identity data or imply that device biometrics validate civil identity.
- Do not invent backend behavior or authorization states.

## Deliverables
Provide the design-file link, exact screens/components changed, reusable components, interaction states, implementation notes, and decisions requiring approval. Do not claim a design was synchronized to code unless verified.
