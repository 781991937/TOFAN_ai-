# TOFAN Academic Lesson Depth

## الهدف

توحيد الحد الأدنى للمحتوى التعليمي في مكتبة TOFAN عبر جميع التخصصات العالمية المضمنة في الكتالوج، مع منع الاعتماد على قالب درس عام لكل المقررات.

## بنية المقرر

كل مقرر مولد في الكتالوج يمر بست مراحل:

1. الأساس المفاهيمي.
2. البنية والمكونات.
3. التطبيق الموجه.
4. التحليل والمقارنة.
5. التصميم والتحقق.
6. التكامل والمشروع.

كل مرحلة تحمل تعريفًا ومحتوى ومصطلحات وأمثلة وتطبيقات وتدريبًا وتقييمًا ودليل مهارة ومشروعًا.

## التخصصية

توجد مكتبة `academic_lesson_blueprints.dart` وتختار مخططًا حسب عائلة المقرر. تشمل المخططات المتخصصة:

- البرمجة وPython.
- الخوارزميات وهياكل البيانات.
- البيانات وقواعد البيانات.
- تعلم الآلة والذكاء الاصطناعي.
- الشبكات.
- أنظمة التشغيل.
- الأمن السيبراني.
- هندسة البرمجيات وDevOps.
- الويب.
- معمارية الحاسوب.
- الرسوميات.
- HCI والتصميم.
- الرياضيات والإحصاء.
- الحوسبة السحابية.
- الأنظمة المضمنة وIoT.
- التحليلات وذكاء الأعمال.
- تقنية المعلومات والتشغيل.
- نظم المعلومات والتحول الرقمي.
- إدارة المشاريع.
- البحث العلمي.
- الأخلاقيات والمهنة.
- المشاريع الختامية.

إذا لم يوجد مخطط خاص، يستخدم النظام المعرفة المعيارية المرتبطة بالمقرر ووحداته الكانونية بدل إسناد مقرر غير مرتبط إلى مادة أخرى.

## التقييم

الاختبارات لا تتحقق من حفظ المصطلح فقط. كل درس يربط الأسئلة بالمخرجات والمفاهيم والمهارات، ويطلب تطبيق المعرفة على حالة جديدة وتحليل النتيجة.

## قاعدة مهمة

المخططات هي بنية تعليمية أصلية من TOFAN، وليست نسخًا من محتوى جامعة بعينها. الكتالوج العالمي يستخدم جامعة صنعاء كمرجع تنظيمي فقط، بينما المعرفة مصممة لتكون قابلة للنقل بين الجامعات والطلاب.

## الخطوة التالية

المرحلة التالية هي ربط هذه الدروس بمحرك المعرفة والرسم المعرفي والمهارات والخبرة، بحيث لا تكون الدروس مجرد صفحات ثابتة، بل وحدات معرفة قابلة للاسترجاع والتقييم والتطبيق داخل TOFAN AL-ABQARI.
