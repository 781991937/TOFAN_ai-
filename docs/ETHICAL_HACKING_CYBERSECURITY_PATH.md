# TOFAN — مسار الهكر الأخلاقي والأمن السيبراني

## الهدف

تم تعميق تخصص **الأمن السيبراني** ليشمل مسارًا عمليًا في **الهكر الأخلاقي واختبار الاختراق** ضمن منهج أكاديمي منظم.

المسار مبني على ثلاثة مبادئ:

1. **التفويض والنطاق أولًا**: لا يبدأ الاختبار قبل تحديد الهدف المصرح به وحدود الاختبار.
2. **التعلم داخل مختبرات آمنة**: التطبيقات الهجومية التعليمية تستخدم بيئات يملكها النظام أو يمنح الطالب إذنًا صريحًا لاختبارها.
3. **الدليل ثم المعالجة ثم إعادة الاختبار**: لا تنتهي المهمة عند اكتشاف المشكلة، بل بتوثيقها وإصلاحها والتحقق من الإصلاح.

## المسار الأكاديمي

يشمل التخصص الآن موضوعات مثل:

- أساسيات الحوسبة الآمنة
- البرمجة للأمن السيبراني
- الشبكات وأمن الشبكات
- أنظمة التشغيل والأمن
- التشفير التطبيقي
- أمن تطبيقات الويب
- الاستجابة للحوادث
- تحليل البرمجيات الخبيثة
- اختبار الاختراق الأخلاقي 1
- اختبار الاختراق الأخلاقي 2
- أمن الشبكات المتقدم
- أمن قواعد البيانات
- التحقيق الجنائي الرقمي
- أمن الحوسبة السحابية
- الهجوم والدفاع في المختبرات الأمنية
- أمن البرمجيات وDevSecOps
- إدارة المخاطر والحوكمة
- تقييم الاختراق وكتابة التقارير
- تمارين الفريق الأحمر والأزرق

## منهجية الاختبار

يعتمد مسار تطبيقات الويب على مجالات اختبار مثل:

- جمع المعلومات ورسم سطح الهجوم
- إدارة الهوية
- المصادقة
- التفويض
- إدارة الجلسات
- التحقق من المدخلات
- معالجة الأخطاء
- التشفير
- منطق الأعمال
- اختبار الواجهات البرمجية

وهذه المجالات مستمدة كمرجع منهجي من OWASP Web Security Testing Guide، مع تحويلها إلى محتوى تعليمي أصلي وتمارين محلية داخل نطاقات مصرح بها.

## دور TOFAN AL-ABQARI

العبقري طوفان لا يتحول إلى أداة اختراق مفتوحة. داخل مسار الأمن السيبراني يعمل كمدرب/مخطط أمني يستطيع:

- تفسير المفاهيم الأمنية.
- بناء خطة اختبار لمختبر مصرح به.
- ربط الثغرة بالمفهوم والمهارة والمقرر.
- تحليل نتائج الاختبار التي يقدمها الطالب.
- اقتراح ضوابط ومعالجات.
- إعداد هيكل تقرير اختبار اختراق.
- اقتراح إعادة اختبار بعد الإصلاح.
- تشغيل سيناريوهات محاكاة تعليمية ضمن حدود النظام.

أما العمليات عالية التأثير أو أي إجراء خارجي فيتطلب صلاحيات واضحة وموافقة مناسبة، ولا توجد في طبقة المعرفة صلاحية تلقائية لتنفيذ عمليات هجومية على أنظمة حقيقية.

## مخرجات الطالب

لكل مشروع أو مختبر أمني يمكن أن يسجل النظام:

- الهدف والنطاق.
- الأصول المصرح باختبارها.
- منهجية الاختبار.
- الأدلة.
- الثغرات المكتشفة.
- الأثر والمخاطر.
- المعالجة المقترحة.
- نتيجة إعادة الاختبار.
- المهارات التي أثبتها الطالب.

هذا يربط **المقرر → المختبر → المهارة → التقييم → المشروع → العبقري** بدل جعل الهكر الأخلاقي وحدة منفصلة عن بقية النظام.
