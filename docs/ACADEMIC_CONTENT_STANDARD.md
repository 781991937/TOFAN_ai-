# TOFAN Academic Content Standard

Every lesson follows: Study -> Practice -> Assessment -> Analysis -> Skill Update -> Project.

Each lesson must define concepts, learning outcomes, key terms, examples, graduated practice, topic-specific assessment, error analysis, skill update evidence, and an applied project.

The global computing library uses CS2023 as a reference framework: Knowledge Areas -> Knowledge Units -> Topics -> Learning Outcomes. Content is original TOFAN instructional material, not copied university courseware.
