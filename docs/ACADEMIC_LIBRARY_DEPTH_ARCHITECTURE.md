# TOFAN Academic Library — Curriculum Depth Architecture

## Purpose

The academic library is a global computing curriculum, not a single-university course list. Sana'a University remains the reference organizational structure, while the academic content is reusable across all supported specializations.

## Depth model

Every course exposed by AcademicCatalog.universities is normalized to at least six learning lessons:

1. Foundation and terminology
2. Core concepts and components
3. Applied problem solving
4. Knowledge-unit deep dive
5. Advanced analysis and application
6. Integration and mini-project

Each generated or normalized lesson carries:
- definition
- learning outcomes
- key terms
- examples
- applications
- guided practice
- assessment questions
- project evidence
- concept identifiers
- skill identifiers
- error-analysis guidance

## Specialization coverage

The current global catalog covers four years and eight semesters for:
- Computer Science
- Software Engineering
- Information Technology
- Information Systems
- Data Science
- Cybersecurity
- Computer Engineering
- Graphics and Human-Computer Interaction
- Artificial Intelligence reference program

The depth layer applies to hand-authored reference courses as well as generated global courses, so the application does not expose one shallow learning model for one specialization and a deeper model for another.

## Knowledge grounding

Course retrieval is connected to the canonical knowledge-area and knowledge-unit catalogs. The structure follows the knowledge/competency separation used by CS2023: knowledge units organize content, while learning evidence expresses what the learner can explain, apply, evaluate, and develop.

TOFAN content is original application content; CS2023 is used as curriculum-structure guidance, not copied as course text.

## Learning lifecycle

Course → Lesson → Practice → Assessment → Analysis → Skill Evidence → Project → Experience

The same evidence can therefore be consumed by the Abqari knowledge graph, learning-gap engine, project engine, and experience memory.

## Quality gate

The curriculum-depth test requires:
- four years per specialization
- eight semesters per specialization
- at least six lessons per course
- learning outcomes, practice, assessment, project, and skill evidence on every lesson
- canonical knowledge-area and knowledge-unit references on every course

This is a structural quality gate. Academic subject-matter depth will continue to be expanded course-by-course; a six-lesson container is not treated as proof that a subject is academically complete.
